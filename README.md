# MTA Ridership Trends After COVID-19

📌 **Purpose of the Project**

This project analyzes MTA ridership data from 2019–2025 to understand how public transportation usage changed following the COVID-19 pandemic. The main objectives are:

* To identify which transit mode recovered the fastest after the pandemic.
* To analyze weekday vs. weekend ridership variation across different transit systems.
* To provide data-driven recommendations for improving MTA service planning and resource allocation.

---
🔍 **Analysis Performed**

1. Data Loading & Preparation
2. Post-COVID Recovery Analysis by Transit Mode
3. Weekday vs. Weekend Ridership Variation

---

📌 **Results**

The project provides insights into:

* Which MTA transit mode (Subway, Bus, LIRR, Metro-North) recovered fastest relative to 2019 pre-pandemic levels.
* Which transit system shows the biggest gap between weekday and weekend ridership, revealing commuter dependency patterns.
* Recommendations for bus service recovery and weekend schedule optimization.
